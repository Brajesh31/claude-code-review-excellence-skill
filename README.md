# Code Review Excellence

A collaborative code review skill focused on constructive feedback, systematic analysis, and shared engineering improvement.

## Capabilities

- Review changes for correctness, security, performance, and maintainability.
- Identify issues and group them by severity.
- Explain findings with evidence, rationale, and practical recommendations.
- Ask focused questions when intent or requirements are unclear.
- Support consistent review standards and developer mentoring.

## Expected output

Reviews should provide a concise summary, severity-ranked findings, actionable suggestions or questions, and relevant test or coverage notes.

## Usage

Use this skill when reviewing pull requests, establishing team review practices, mentoring developers, or auditing changes. Read the project context and requirements first. Use the implementation playbook in `resources/` when detailed patterns or templates are needed.

Treat review as collaborative risk reduction, not gatekeeping. Avoid unsupported findings and stylistic nitpicks.
